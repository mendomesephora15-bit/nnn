# BON GOUT — Frontend HTML & CSS

## Open in Visual Studio Code
1. Extract the ZIP file.
2. Open the extracted `BON-GOUT-VISUAL-CODE` folder in VS Code.
3. Open `index.html` with the Live Server extension.
4. Navigate using the menu.

## Files
- `index.html`: Home
- `menu.html`: Menu & Ordering layout
- `contact.html`: Contact & Reservations layout
- `admin.html`: Admin dashboard layout (open directly; not in customer navigation)
- `css/style.css`: Shared customer website styles
- `css/admin.css`: Admin dashboard styles

## Important
This delivery is the HTML/CSS presentation layer. Forms, category filtering, cart actions, order submission, authentication, live admin data and Supabase storage/database operations are not active yet. They will be implemented with the JavaScript files in the next project stage, as required by the project brief.

The restaurant address, telephone and email are placeholders and should be replaced with the real details. Sample menu items and prices are visual examples only. The featured-food cards will later be loaded from Supabase.

The images and Google Fonts are loaded from external services, so an internet connection is required for them to display.
